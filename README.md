# Flu Time Series Forecasting

Forecasting weekly outpatient ILI (Influenza-Like Illness) visit volumes using CDC FluView data.

## Project Goals
- Acquire and analyze ILI trends across HHS regions
- Build seasonal + autoregressive models
- Deploy a visual dashboard for forecasting insights
